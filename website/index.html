CAPABILITIES

Current behavior.

  • Runtime

    One Rust executable stores state in SQLite. No container or separate runtime is required.

  • Tools

    The agent has a shell, DuckDuckGo search, Telegram messages and file transfer, and persistent goal, memory, and wake-time controls.

  • Autonomy

    RedRock runs with the installing user's permissions, acts without per-action approval, pursues goals between messages, and schedules its own wake time.

  • State

    Goals, long-term memory, and conversations are stored in SQLite. Context is compacted at the configured threshold.

  • Services

    DeepSeek deepseek-v4-pro is the default model. Telegram accepts private messages and documents from configured user IDs.

  • Installation

    Graphical setup supports Windows and Debian desktops. redrock install --cli supports headless Linux.

BEFORE YOU RUN IT

This agent has your account's permissions.

RedRock can read, change, transmit, or delete accessible files and run arbitrary commands without per-action approval. It has no audit history, rollback, or privacy guarantee. Run it only on a computer you are prepared to dedicate to it.
